## Completed

1. **Standard missile damage dice.** The separate numeric-only missile prompt is replaced by the shared character damage-dice renderer. Players can roll red D8s on screen or use the standard manual-total alternative, inspect a readable result, then Confirm and Submit. The impact reminder hides while the one damage window is open. Closing the window does not apply damage or unpause ATB. Failed loading offers Retry Loading Dice; failed submission retains the result and offers Retry Submit. Resolved/removed impacts close stale windows. GM ownership, player exclusion, operator removal and server restart behavior are preserved.
2. **Automatic missile multiplier.** The window states that the multiplier is applied automatically and has no multiplier entry. The existing server rule remains x1 with active shields and x5 without shields. No new overflow rule was introduced. Invalid totals are still rejected and successful submissions remain idempotent.
3. **Persistent SIC damage warning.** A compact red status row names installed impaired/destroyed systems on the viewer's own/occupied ships; the GM sees all ships. Its red indicator pulses continuously while the text stays readable, and reduced motion uses a steady light. It survives tabs, consoles, reload and combat ending, then clears on repair/removal. It shares reserved header space with Enemy Locked On rather than covering console controls. It also works in the standalone encounter view. Enemy system names are not added to unrelated player warning streams.
4. **Missile facing.** The pilot map now updates the actual missile body rotation during flight. Its cached map also responds to missile phase changes. Sensor and weapon map caches include heading/phase changes; the common map renderer retains the same heading marker. Homing, acceleration, pause behavior, salvo offsets and existing visual effects remain intact.
5. **Named component damage.** Combat Activity names a specifically locked-on SIC when Hull damage reaches it. The attacker's name comes from its analyzed snapshot; without that knowledge, the report says Targeted SIC. The defender can see its own system name without learning the attacker's identity. Ordinary ship-level hits and reflection retain their existing reporting behavior.
6. **Relevant missile damage reports.** Zero-value shield and Hull damage channels are omitted. Reports retain the rolled total and actual damage; no-damage cases say so explicitly. Combat Activity remains non-flashing.
