Cause and correction
The shared popup enhancer treated immersive console dialogs as ordinary popup menus. Its sci-fi-dialog-surface class overrode their original artwork, spacing, borders, typography and controls. Console-specific CSS itself had not changed since the pre-popup release (8787571).

The enhancer now excludes the actual immersive console surfaces: pilot, weapons, shields, sensors/probes, lock-on, utility/crew rooms, hacking, Transporter and Planetary Cleanser. Static catalog snapshots receive the same protection. Existing console styles/artwork render directly; no old gameplay code was restored. Compact ship/action planners and genuine confirmation/menu popups retain their vector frames, including prompts opened from consoles. Existing dismissal behavior is preserved.
