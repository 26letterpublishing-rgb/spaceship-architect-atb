Implemented

- Optional collapsed alternate-file controls in individual GM saves, including maps, Story, roster/NPCs, shops, arenas and embedded character/ship editors. Keywords appear in the downloaded filename; default-file and condition metadata are also embedded in the save.

- Story File Load and location Arrival Content support alternatives. Packaged variants are indexed without loading their content; conditional files cannot be Load at Start. Suggestions show the selected filename and reason, then retain the existing GM-confirmed loading workflow.
- Preview Conditions simulates elapsed time and switch states without changing the campaign. Only brief GM Settings/Script Help additions.

Decisions
- Clock persistence checkpoints occur every five seconds while active, plus existing saves and disconnect handling. A process crash can therefore lose a few seconds of wall-clock progress; restored sessions do not count downtime.
- Switches are named campaign story outcomes, initially OFF. Their current values and change timestamps stay in Campaign saves; authored definitions and file conditions travel in Modules.
- Save-file conditions use metadata rather than trying to infer meaning from filename text. Existing content is never automatically overwritten when a condition changes.
- Default filenames and matching alternate types are validated. Modules check file dependencies; external prompts remain an explicit exporter choice.
- Existing Story switches are reused by keyword on import; a colliding ordinary reward keyword is reported instead of silently breaking the branch.
- The header shares space between identity, clock and actions; the existing responsive two-row arrangement is retained at narrow widths. Existing controls remain available.
